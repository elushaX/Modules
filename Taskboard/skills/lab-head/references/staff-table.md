# Таблица «Загрузка сотрудников» (форма НТО-8)

Образец: `~/work/claude/lab/Загрузка сотрудников НТО-8(1).xlsx` (лист `Лист1`).
Готовые заполненные файлы: `Загрузка сотрудников ОРСПО_лаборатория Мотина Н.А.xlsx`,
`… Чугунова И.В.xlsx` — брать как эталон формулировок.

## Структура

| Ячейка | Содержимое |
|---|---|
| строка 2 | шапка: Наименование подразделения / Наименование должности / ФИО / Функции / Проекты (вовлеченность) / Комментарии / Квалификация (ключевые метрики) |
| строка 3 | нумерация колонок 1..7 |
| строка 4 и ниже | данные, колонки B..H |

Шрифт Times New Roman 10, перенос по словам, выравнивание по верхнему левому краю, тонкие
границы. Файл простой (нет drawings) — **openpyxl безопасен**. Стиль новых строк копировать
из строки 4:

```python
styles = {c: copy.copy(ws.cell(4, c)._style) for c in range(2, 9)}
...
cell._style = copy.copy(styles[c])
ws.row_dimensions[r].height = 135
```

Ширины колонок: B 12, C 25, D 25, E 40, F 25, G 55, H 45.

## Правила заполнения (проверены на замечаниях)

- **B — подразделение:** только сокращение (`ОРСПО`), без расшифровки и без лаборатории.
- **C — должность:** ровно как в план-факте; для начальника лаборатории, числящегося ведущим
  специалистом, писать штатную должность, а фактическую роль вынести в «Функции».
- **D — ФИО:** как в учётной системе, с пометкой `(осн.)`; для новых — `(осн., принят с ДД.ММ.ГГГГ)`.
- **E — функции:** перечень обязанностей через `;`, безлично.
- **F — проекты (вовлеченность):** проект и доля в процентах. Если руководство просит показать
  всех занятыми одним проектом — `Восход (100)`, без Дебюта, УПП и «Восход НР».
  Иначе доли брать из плана на текущий месяц (столбец `I` × 100).
- **G — комментарии:** чем занят сейчас и чем занимался, **без номеров задач Jira и названий
  репозиториев**. Технологии называть можно.
- **H — квалификация:** список через `;` в столбик, с уровнем: `Программирование в среде C++
  (Senior, Teamlead)`, `(ведущий уровень)`, `(Middle)`, `(Junior)`. Последней строкой —
  ограничение или особенность, если она есть.

## Словарь формулировок

**Сильный сотрудник:** «ведёт направление самостоятельно, без необходимости детальной постановки
задач»; «способен вести проект целиком и обучать новых сотрудников»; «консультирует смежные
подразделения»; «его наработки закладываются в основу Платформы»; уровень `Senior` в квалификации.

**Средний:** «работает самостоятельно, задачи закрывает в срок»; «координирует работу
тестировщиков»; «объём задач стабильно растёт».

**Слабый (без эмоций, фактами):** «задачи как правило переходят на следующий месяц»; «темп ниже,
чем у сотрудников сопоставимой должности»; «глубина проработки и самостоятельность ниже
ожидаемых для ведущего специалиста — требуется постановка задач мелкими шагами и регулярный
контроль промежуточных результатов»; «квалификация ниже уровня занимаемой должности»;
«требуется сопровождение и контроль со стороны более опытных сотрудников».

**Новый сотрудник:** «проходит онбординг и приёмку кодовой базы»; «загрузка по проектам и оценка
квалификации будут уточнены по итогам испытательного срока».

**Неполная ставка:** «работает на 0,5 ставки, объём и качество работ соответствуют должности и
занятости».

## Запрещено

- Оценочные суперлативы: «сильнейший», «самая сложная часть», «показывает хороший уровень»,
  «работает инициативно», «даётся тяжело».
- Отсутствия, отпуска, больничные.
- Номера задач Jira, названия веток и репозиториев.
- Приписывание технологий, которых у человека нет в реальной истории задач и коммитов —
  проверять по Jira за **всю** историю, а не за последний месяц (иначе профиль сузится до
  текущей задачи).
